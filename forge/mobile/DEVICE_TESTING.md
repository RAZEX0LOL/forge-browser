# Проверка Forge на устройствах

Это чек-лист для локального кандидата, не подтверждение готовности браузера.
До установки согласуйте конкретное устройство и сохранность его данных.
Используйте тестовые аккаунты и отдельные устройства/профили, не рабочую сессию.

## Установка

- Android: выберите APK своей архитектуры (обычно `arm64-v8a`). Это debug-подпись,
  не стабильный релиз. Не удаляйте существующий Forge ради установки: при конфликте
  подписи остановитесь, а не стирайте данные. Обновление может запросить доступ к
  камере/микрофону только после явного действия; установка сама доступ не выдаёт.
- iPhone/iPad: App Store Connect IPA нельзя поставить напрямую. Нужна отдельно
  согласованная загрузка/обработка TestFlight либо профиль разработки для выбранного
  устройства. Не используйте обход проверки подписи или неофициальную переподпись.
- Сверьте SHA-256 с `SHA256SUMS` именно этого кандидата. Старые опубликованные
  APK/TestFlight build 3 не содержат нынешние изменения интерфейса и приватности.

## Камера и микрофон

Для начала используйте `fixtures/media-permissions.html` на контролируемом вами
HTTPS-сайте с доверенным сертификатом. Страница показывает только локальное
превью/уровень микрофона: нет записи, WebRTC-соединения или отправки потока.
Она **не останавливает треки по visibilitychange**: иначе скрыла бы ошибку браузера.
Размещение страницы на сервере — отдельное действие; ничего автоматически не
разворачивается. Не добавляйте исключения TLS и не используйте случайные сайты
проверки камеры. Работа физического датчика требует вашего явного согласия.

Заполните результат отдельно для iPhone, iPad и Android:

| Проверка | Ожидаемый результат | Факт |
| --- | --- | --- |
| Камера / микрофон / оба | Верный HTTPS-origin и назначение в запросе; без пути/query | Не проверено |
| «Запретить» | Нет захвата и индикатора; нет автоматического разрешения | Не проверено |
| Отказ ОС | Даже после согласия сайту доступ не выдаётся | Не проверено |
| «Разрешить» | Локальное видео/уровень звука и системный индикатор | Не проверено |
| Смена вкладки при запросе | Старый запрос отменён, новая вкладка доступ не получает | Не проверено |
| Смена сайта при запросе | Поздний ответ ОС не разрешает доступ другой странице | Не проверено |
| Новая вкладка при захвате | Захват прекращается; возврат требует загрузить сохранённую страницу | Не проверено |
| Сворачивание / блокировка | Захват прекращается; проверить индикатор ОС, а не только превью | Не проверено |
| Приватная вкладка | Такие же явные запросы; URL не появляется в обычной сессии | Не проверено |
| Закрытие приватной группы / очистка | Захват и незавершённые запросы прекращаются | Не проверено |
| Сторонний iframe | Доступ отклонён | Не проверено |

Системное разрешение относится ко всему приложению и сохраняется вне приватного
режима. Очистка данных сайтов его не отзывает. Если индикатор захвата не исчезает,
закройте тест, отзовите разрешение в настройках ОС и зафиксируйте ошибку. Не делайте
вывод о прекращении захвата лишь по исчезновению изображения со страницы.

Отдельно проверьте реальный WebRTC-звонок с тестовым собеседником: разрешения не
доказывают работу кодеков, ICE/TURN, смены аудиоустройства или сети. Не записывайте
звонок и не используйте чужой аккаунт без согласия. Фоновые звонки сейчас намеренно
не поддерживаются: уход с вкладки/из приложения выгружает страницу с захватом.

## Данные, загрузки и интерфейс

1. На HTTPS-сайте с тестовым аккаунтом создайте обычную сессию. Приватная вкладка
   не должна видеть её cookies; обычная — cookies приватной группы.
2. Закройте всю приватную группу и откройте новую: прежняя приватная сессия исчезла.
3. Отмените диалог очистки: данные и вкладки остаются. Подтвердите: тестовый аккаунт
   вышел, приватные вкладки закрыты, обычные адреса сохранены без автозагрузки.
4. Скачайте безопасный тестовый файл, отмените и повторите экспорт в системные
   «Файлы»/Documents. Сверьте байты/хеш. Уже экспортированный файл очистка не удаляет.
5. Пока открыт системный экспорт, очистка не начинается. При уходе в фон обычная
   незавершённая загрузка отменяется; возобновление после смерти процесса не обещано.
6. Перезапустите приложение: обычный список восстановлен без автоматического
   перехода; приватные адреса не восстановлены. Проверьте прямую сеть устройства:
   тестовый relay симулятора не является такой проверкой.
7. Проверьте клавиатуру, поворот, safe area, крупный шрифт, VoiceOver/TalkBack и iPad.

## Запись результатов

Для каждого прогона: платформа/версия ОС, модель без серийного номера, версия/build,
SHA-256 пакета, шаги, ожидание/факт. Не включайте UDID, cookies, токены, персональные
URL, запись звука/видео или скриншоты чужих аккаунтов. Не отмечайте «пройдено» по
результатам симулятора или mock-разрешений вместо реального устройства.
